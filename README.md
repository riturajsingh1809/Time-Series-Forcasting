# Time Series Forecasting

*Developed by Ritu Raj Singh*

## Project Overview

This project focuses on Time-Series Forecasting to identify historical sales patterns, trend, seasonality and generate future sales forecasts.

The project follows a structured Data Analyst workflow using Excel, Python and Tableau.

## Tools Used

* Excel - Data Cleaning
* Python / Google Colab - Data Analysis and Forecasting
* Pandas - Data Processing
* NumPy - Numerical Analysis
* Statsmodels - Time-Series Analysis and SARIMA Forecasting
* Tableau - Data Visualization and Dashboard
* GitHub - Project Documentation and Version Control

## Project Workflow

### 1. Data Cleaning - Excel

The raw dataset was cleaned in Microsoft Excel.

The cleaning process included:

* Checking missing values
* Checking duplicate records
* Standardizing text values
* Cleaning date values
* Checking invalid values
* Preparing the dataset for analysis

The cleaned dataset was then used for Python analysis.

### 2. Python Analysis

The cleaned dataset was analyzed using Python in Google Colab.

The analysis included:

* Loading the cleaned dataset
* Preparing the time-series data
* Monthly sales aggregation
* Descriptive statistics
* Moving average analysis
* Trend analysis
* Seasonal decomposition
* Stationarity testing
* Train-test split
* Naive baseline model
* SARIMA model
* Model evaluation
* Model comparison
* Future sales forecasting
* Forecast intervals

### 3. Tableau Dashboard

Tableau was used to create the final visualization and dashboard.

The dashboard includes:

* Total Sales KPI
* Average Sales KPI
* Sales Trend
* Actual vs Forecast
* Seasonal Analysis
* Model Comparison
* Forecast Table

## Forecasting Approach

A SARIMA model was used to capture both trend and seasonal patterns in the time-series data.

The model was evaluated against a Naive Baseline using MAE, RMSE and MAPE.

## Business Objective

The objective of the project is to provide reliable forward-looking sales estimates that can support planning, capacity and budgeting decisions.

## Conclusion

The project demonstrates an end-to-end Data Analyst workflow from Excel-based data cleaning to Python-based time-series analysis and forecasting, followed by Tableau visualization and dashboard development.
